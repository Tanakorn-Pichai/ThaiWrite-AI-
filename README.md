# ThaiWrite AI (ระบบตรวจเอกสารภาษาไทยอัจฉริยะ)

ระบบตรวจคำผิด ไวยากรณ์ ระดับภาษา และโครงสร้างเอกสารวิชาการภาษาไทย พร้อมหน้าพรีวิวตรวจแก้เอกสารแบบเต็มจอเสมือนจริง (Interactive Fullscreen A4 Document Review Workspace)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. การดึงข้อมูลจริงจากไฟล์และข้อความ (Real Data Ingestion)
- **ดึงข้อความจริงจากไฟล์เอกสาร (.docx, .txt, .pdf):**
  - **ไฟล์ Word (.docx):** ถอดรหัสโครงสร้าง XML ดึงข้อความภาษาไทยจริงโดยอัตโนมัติผ่าน `mammoth`
  - **ไฟล์ PDF (.pdf):** ใช้ `pdfjs-dist` (Mozilla PDF.js) สกัดข้อความแท้จริงจากทุกหน้ากระดาษ พร้อมตัวกรองป้องกันไวยากรณ์ไบนารี (`%PDF-`, `obj`, `Type`) รั่วไหล
  - **ไฟล์ข้อความ (.txt):** อ่าน UTF-8 Native Stream
  - **กล่องป้อนข้อความ (Textarea):** วิเคราะห์ข้อความสดที่ผู้ใช้พิมพ์หรือแก้ไข
- **การจัดหน้า A4 อัตโนมัติ (Dynamic Multi-page A4 Chunking):**
  - แบ่งข้อความจริงของผู้ใช้ลงในหน้ากระดาษ A4 มาตรฐานตามสัดส่วนย่อหน้า (~1,200 - 1,800 ตัวอักษร/หน้า)
  - กำกับหมายเลขคำผิด `[1]`, `[2]`, `[3]`, ... เชื่อมโยงกับหน้าบันทึกข้อคิดเห็นอย่างถูกต้อง

### 2. พื้นที่ตรวจเอกสารเต็มจอพร้อมแถบควบคุมโปร่งใส (Fullscreen Glassmorphic Overlays)
- **ขยายเต็มหน้าจอ 100% (100vw × 100vh):**
  - เมื่อกดตรวจเอกสาร ระบบจะเปิดหน้าพรีวิวเต็มจอเสมือนจริง โดยซ่อน Header/Footer หลัก เพื่อให้กระดาษ A4 ได้รับพื้นที่แสดงผลสูงสุด
- **แถบควบคุมลอยแบบโปร่งแสง (Hover Reveal Overlays):**
  - แถบควบคุมด้านบนและแถบดาวน์โหลดด้านล่างถูกออกแบบให้อยู่ในสถานะโปร่งแสง (`opacity: 40%` พร้อม `backdrop-blur-md`) ไม่บดบังตัวอักษรของเอกสาร
  - **เมื่อเลื่อนเมาส์ไปใกล้:** แถบจะสว่างขึ้นเป็น `opacity: 100%` อัตโนมัติ เพื่อให้คลิกเปลี่ยนหน้า, ซูม หรือดาวน์โหลดได้อย่างสะดวก
- **เลือกหน้าแบบดรอปดาวน์ (Dropdown Page Selector):**
  - รวมรายการหน้าทั้งหมดไว้ใน Dropdown เมนู ไม่ล้นหน้าจอแม้เอกสารจะมีหลายสิบหน้า
  - มีปุ่มลัด `[◀ ก่อนหน้า]` และ `[ถัดไป ▶]` ขนาบข้างสำหรับคลิกเปลี่ยนหน้าได้อย่างรวดเร็ว
  - มุมมอง **เทียบ 2 ฝั่ง (Split Screen)** แสดงกระดาษ A4 ต้นฉบับและฉบับตรวจแก้คู่กันและเปลี่ยนหน้าพร้อมกัน

### 3. ตรวจจับคำผิดและโครงสร้างตามแม่แบบ (Linguistic & Template Engine)
- **ตรวจสอบคำสะกดผิด (Spelling):** เช่น สัมนา → สัมมนา, อนุญาติ → อนุญาต, กฏเกณฑ์ → กฎเกณฑ์, ผัดวันประกันพรุ่ง → ผลัดวันประกันพรุ่ง ฯลฯ
- **ตัดกริยาช่วยและคำฟุ่มเฟือย (Grammar & Redundancy):** เช่น ทำการวิเคราะห์ → วิเคราะห์, มีความต้องการที่จะ → ต้องการ, ได้ทำการ → ได้
- **ปรับระดับภาษาเชิงวิชาการ (Academic Tone):** เช่น เยอะแยะ → จำนวนมาก, ในส่วนของ → สำหรับ, จริงๆ → แท้จริง
- **ตรวจเทียบโครงสร้างแม่แบบ:** รองรับแม่แบบวิทยานิพนธ์, รายงานโครงงาน 5 บท, บทความวิจัย TCI, หนังสือราชการ และแม่แบบเฉพาะที่ผู้ใช้อัปโหลด

### 4. การส่งออกเอกสาร 2 หน้ามาตรฐาน (Export System)
- **PDF (.pdf):** หน้า 1-N เป็นเนื้อหาพร้อมหมายเลขกำกับ + หน้าสุดท้ายเป็นหน้าบันทึกข้อคิดเห็น (Review Comments Sheet)
- **Word (.docx):** เอกสาร Word พร้อมตารางรายการตรวจแก้และข้อคิดเห็นเชิงวิชาการ
- **ดาวน์โหลดทั้ง 2 ไฟล์:** ส่งออกทั้ง PDF และ Word พร้อมกันในคลิกเดียว

## 🛠️ โครงสร้างสถาปัตยกรรม (Project Architecture)

```text
src/
├── components/
│   ├── input/
│   │   ├── FileDropzone.tsx         # จุดรับไฟล์และดึงเนื้อหาจริง (.docx, .txt, .pdf)

│   │   └── ...
│   ├── results/
│   │   ├── DocumentComparePreview.tsx # พรีวิวเอกสารเต็มจอ A4 + แถบโปร่งแสง Hover Reveal
│   │   ├── ResultPanel.tsx          # แผงแสดงสถิติและคะแนนคุณภาพ
│   │   └── ...
│   └── layout/                      # Header, Hero, Footer
├── data/
│   ├── mockAnalysis.ts              # กฎการตรวจไวยากรณ์และวิเคราะห์ข้อความจริง
│   ├── mockDocumentPreview.ts       # ระบบจัดหน้า A4 และสร้าง Annotations จากเนื้อหาจริง
│   └── mockTemplates.ts             # แม่แบบมาตรฐานและการตรวจสอบหัวข้อ
├── utils/
│   ├── fileExtractor.ts             # ตัวถอดรหัสข้อความจากไฟล์ Word/PDF/Text
│   └── documentExport.ts            # ตัวส่งออกเอกสาร PDF & Word แยกหน้าข้อคิดเห็น
├── types/                           # TypeScript interfaces
└── pages/
    └── HomePage.tsx                 # หน้ารวมระบบและสลับมุมมอง Fullscreen
```

## 🚀 การติดตั้งและรันระบบ (Getting Started)

ดูคู่มือการรันฉบับเต็มและวิธีแก้ปัญหาได้ที่ **[RUN.md](./RUN.md)**

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รัน Frontend (พอร์ต 3000)
npm run dev

# 3. (ทางเลือก) รัน Backend ด้วย Docker
cd backend && docker-compose up --build
```
